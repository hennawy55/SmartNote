دفتر العقارات الذكي - نسخة Online Only

الملفات:
- index.html: واجهة التطبيق المتجاوبة.
- Code.gs: Google Apps Script المتوافق مع واجهة التطبيق.
- manifest.json و sw.js والأيقونات: تثبيت التطبيق كتطبيق PWA.

إعداد قاعدة البيانات:
1) افتح Google Sheets المرتبط بمشروع Apps Script المستخدم في رابط Web App.
2) افتح Extensions > Apps Script.
3) إذا كان السكربت المنشور هو نفس السكربت الذي أرسلته، فهو متوافق مع الواجهة ولا يلزم تغييره.
4) إذا أردت استخدام Code.gs المرفق، الصقه في مشروع Apps Script ثم Deploy > Manage deployments > Edit > New version > Deploy.
5) يجب أن يكون Web App متاحاً لمن لديه الرابط (Anyone) حتى تعمل الواجهة.
6) إذا ظهرت الرسالة `invalid_type`، فهذا يعني أن إصدار Web App المنشور لا يتوافق مع الواجهة؛ انشر محتوى Code.gs الحالي كإصدار جديد من Deploy > Manage deployments > Edit > New version > Deploy.

الربط:
- رابط Web App ورمز TOKEN موجودان داخل index.html.
- اسم سجل قاعدة البيانات: SMART_REAL_ESTATE_NOTEBOOK_V1.
- يخزن التطبيق قاعدة بياناته كـ JSON واحد في تبويب Data، مع مصفوفة spaces المطلوبة من السكربت.

ملاحظات مهمة:
- التطبيق Online Only: لا يحفظ بيانات المشاريع أو الوحدات أو العملاء في LocalStorage.
- تتم مزامنة التعديلات من الأجهزة الأخرى تلقائياً كل 5 ثوانٍ أثناء فتح التطبيق واتصاله بالإنترنت؛ تتوقف المزامنة في الخلفية لتقليل الطلبات، ثم تستأنف عند العودة للتطبيق.
- تعرض الرئيسية المتابعات غير المكتملة بترتيب الأولوية (عاجلة، مهمة، عادية)، ثم موعد المتابعة؛ وتعرض أول خمس متابعات.
- فعّل إذن إشعارات المتصفح من زر «تفعيل التنبيهات» في الرئيسية. أثناء بقاء التطبيق مفتوحاً، تظهر إشعارات النظام ونغمة تتكرر كل 15 ثانية للتنبيهات غير المعالجة، قبل الموعد بخمس دقائق للمتابعة المعلقة، وعند حلول موعدها إذا بقيت معلقة، وبعد ساعة من بدء التنفيذ. تفتح التنبيهات الداخلية من أيقونة الجرس أعلى التطبيق مع عدّاد، وتبقى بعد تحديث الصفحة حتى إخفائها أو فتح المتابعة. يمكن إيقاف التنبيهات ساعة ثم إعادة تفعيلها فوراً من زر التبديل في الرئيسية أو لوحة الإشعارات؛ وتُستأنف تلقائياً بعد الساعة. تُحفظ بيانات التنبيهات غير المعالجة ومفاتيح منع التكرار محلياً في المتصفح فقط، ولا تُحفظ بيانات قاعدة البيانات هناك. إذا لم تحدد وقتاً للمتابعة، يُستخدم 09:00 صباحاً. التنبيهات لا تعمل بعد إغلاق التطبيق؛ ذلك يحتاج خدمة Push خلفية.
- تستخدم إشعارات النظام Service Worker؛ يجب استضافة التطبيق على HTTPS. على iPhone/iPad، يلزم iOS 16.4 أو أحدث، إضافة التطبيق إلى الشاشة الرئيسية، وفتحه من الأيقونة قبل منح إذن الإشعارات. نغمة الصفحة تعمل أثناء فتح التطبيق فقط؛ الإشعارات في الخلفية بعد إغلاقه تحتاج خدمة Push خلفية.
- Service Worker يخزن ملفات واجهة التطبيق فقط لأغراض التثبيت؛ لا يخزن بيانات Google Sheets.
- حد حجم JSON الحالي 45,000 حرف وفق السكربت. عند زيادة البيانات سننقل التخزين إلى سجلات متعددة داخل Sheets.
- TOKEN الموجود داخل HTML يمكن استخراجه من ملفات التطبيق؛ لا تستخدم هذا النمط لتخزين بيانات شديدة الحساسية.
- يلزم استضافة الملفات على HTTPS لتثبيت PWA. فتح index.html مباشرة من القرص لا يدعم التثبيت أو Service Worker.
