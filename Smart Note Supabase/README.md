# Smart Note Supabase

نسخة مستقلة قيد التجهيز لترحيل SmartNote من Google Apps Script / Google Sheets إلى Supabase.

## مبدأ العمل
- هذا المجلد مستقل عن `upgrade version` ولا يغيّرها.
- ملفات الواجهة والتصميم واللغة والثيم وأصول Android نُقلت من النسخة المستقرة كبداية.
- لم يتم نقل Backend الخاص بـ Google Apps Script أو أي بيانات أو مفاتيح/أسرار.
- لم يتم ربط Supabase بعد؛ لا تعتبر هذه النسخة جاهزة للتشغيل أو النشر في هذه المرحلة.

## خطة التنفيذ المرحلية
1. تجهيز طبقة Backend جديدة باستخدام Supabase Auth وPostgreSQL.
2. نقل منطق الدخول والجلسات والصلاحيات إلى Supabase مع سياسات RLS.
3. ترحيل عمليات البيانات لكل الوحدات (مساحات العمل، المشاريع، الوحدات، الملاحظات، العملاء، المتابعات).
4. نقل المتابعات الموجهة وسجل الحركة وإعادة الإسناد والملاحظات والإشعارات والأرشفة.
5. اختبار الوظائف والصلاحيات والمزامنة والعمل دون اتصال.
6. إعداد بناء الويب وAndroid مستقلين، ثم اختبارهما قبل أي اعتماد.

## تنبيه
ملف `app.js` لم يُنسخ بعد لأنه يجمع واجهة التطبيق مع اتصال مباشر بواجهة Google Apps Script. سنفصل طبقة البيانات أولاً ثم نربط الواجهة بـ Supabase، لتجنب تشغيل النسخة الجديدة على قاعدة البيانات القديمة بالخطأ.
